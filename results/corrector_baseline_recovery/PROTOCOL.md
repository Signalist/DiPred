# DiPred Corrector 基线恢复协议

本轮首先独立重放 `others` 固定提交 `333934b60b56f6faf97aedd3bd7d1d0ca79c2583` 的旧 rescrct_block。使用旧训练所得权重、gain=0.5、主干原通道归一化、旧 batch=1 零噪声 P 和原有四个评分分区。先逐窗重算发布输出，再使用 NumPy 的物理 MSE 按原轨迹平均。同当前 32 成员均值试验分别解释。

当前统一协议只用 X 和冻结 P，完整真实历史 20 帧至未来 20 帧。P 是同一冻结主干、种子 500000–500031 的 32 成员物理输出均值。复用原 183 个训练窗、24 个开发窗和 24 个历史测试窗。扩展训练窗取核验的旧 819 清单与原 183 清单并集，只用当前获准训练轨迹和完整真实窗口。对新增起点，按当前训练清单顺序对有完整历史的轨迹组成固定批，保持随机数前缀的身份，按种子用正初始噪声逐成员运行原四次去噪并做 float32 成员均值，之后剔除无完整目标的轨迹。每批记录输入和输出哈希。同窗口的 P 在四个正式对照和 R0 间共享。

所有正式组复用旧 Small 训练集的输入通道均值、标准差和公共物理残差 RMS。Point 的网络输出直接作为无量纲残差。Block 的旧接口输出完整坐标场，从其输出减掉网络输入 P 得到无量纲修正。两者均乘相同训练残差 RMS 得到物理 R，发布 Q=P+αR。损失仅为物理残差 MSE 除以公共标量 RMS²。用固定偏置、固定通道缩放、1 个和 4 个真实训练窗验证符号、时序、单位及拟合。诊断使用温和训练设置的第 1000 步预算，记录 0/50/100/250/500/750/1000 步。合成曲线检查两种架构是否捕获至少 90% 初始目标能量，真实小样本曲线用于观察训练拟合。

| 方法 | 架构 | 训练窗口 | 更新 |
| --- | --- | --- | --- |
| R0 | Point | 183 | 上轮原 Adam 设置，核验复用 3 种子至 1000 步 |
| R1 | Point | 183 | AdamW，2000 步 |
| R2 | Block | 183 | AdamW，2000 步 |
| R3 | Point | 扩展 | AdamW，2000 步 |
| R4 | Block | 扩展 | AdamW，2000 步 |

R1–R4 各 seed 42、43、44，AdamW 初始 3e−4，余弦退火按 2000 次更新（首次使用初始率，最后一次使用 1e−6），weight_decay 1e−5，梯度全局范数裁剪 1，batch 8。保存 0/50/100/250/500/750/1000/1500/2000 步。使用相同数据的组沿用同一采样计划。轨迹均匀有放回采样，再在该轨迹的合法窗中均匀有放回采样。在 183 窗协议中沿用 R0 的前 1000 步采样索引，额外 1000 步取独立确定性采样流。

按每个种子的完整物理开发 MSE 选择检查点和 α。每个检查点比较 0、1、开发解析 α=clip(C/E,0,1)，E=0 时解析解取 0。同分优先早步、较小 α，再依固定顺序优先开发拟合。另冻结各组第 1000 步和最后一步的原输出及开发拟合、Native 作为共同零修正对照。R0 原选择按上轮冻结记录逐项校验。以三个训练种子平均开发 gain 决定候选，要求至少两种子非零正收益，按最大开发 gain 选择并冻结该候选。测试中单列三种子并报告区间和改善轨迹比例，稳定收益需方向跨种子一致且轨迹区间排除零。没有满足条件时报告全部负结果及失败来源。

完整训练曲线按原轨迹等权，同时保留 R0 上轮的训练窗等权口径以核查重现。开发、测试的两窗口/轨迹天然等权。正式评价只在所有候选及选择写入冻结文件后读当前协议历史测试集。用原轨迹作为配对 bootstrap 单位（10,000 次，种子 42），先平均窗口再平均训练种子。逐 lead 能量修正率以该 lead 的原真实残差平方能量为分母，计算相对 Native 的能量降低。历史测试已多轮使用，解释为探索性结果。

## 复现

在 Corrector 工作树执行。旧批一缓存与检查点来自保留的 Forecast/Runtime。固定来源哈希见运行产物。

~~~bash
source env.sh
export PYTHONPATH="$PWD/../Forecast/Runtime/.deps"
python -m research.corrector_baseline_recovery.run --out /path/to/new/results
~~~
