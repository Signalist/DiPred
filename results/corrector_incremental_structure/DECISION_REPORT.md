# DiPred 残差增量、时间结构和反馈一致性

按登记的开发集主规则选定 **IB_match2**。新候选 **IB_match2** 使用第 6000 步权重。开发主规则所选配置共有 1,689,580 个参数，本轮头部有 38,082 个可训练参数。单窗端到端中位延迟为 8.72 ms，计入当前发布中实际调用的四次 DiPred 去噪和 S3，已经发布的历史状态从缓存读取。

开发所选端点为 IB_match2 MSE 0.00014124，相对 Native +8.311%，相对 S3 +3.179%，相对自身对照 +1.160%。历史 24 窗上为 IB_match2 MSE 0.0001052，相对 Native +5.746%，相对 S3 +1.199%，相对自身对照 +0.343%。历史队列相对 S3 的配对区间为 [-0.841%, +2.850%]，6/12 条轨迹改善。固定第 6000 步时，IB_match2 MSE 0.0001052，相对 Native +5.746%，相对 S3 +1.199%，相对自身对照 +1.109%。

登记的 31 个核心配置和 18 个工况复验均完成。复用了主训练的四个 OOF 教师、一套完整训练 S3、三个工况各五个隔离 S3、一套直接 E 的第 1000 步全状态、对应 K=20 基线以及已发布的单路径 Native 缓存。历史 B/E 与时间目标保留原权重和选法。各配置的实际更新量、监督窗口暴露量与耗时见训练记录。结构模型归档各登记步的全状态，直接 E 校准臂保留共有的第 1000 步全状态、全套权重检查点及 22 个分支全状态。原训练器轮替临时日志后，仍有 14 个分支全状态未归档，清单见 `calibrated_state_archive.json`。

## 1. 相近初始梯度影响下的时间结构

开发结果部分支持正常 TM2。四项分别为 Ecal_match2_0.1 对 Ecal_diag_0.1 -0.053%、Ecal_match2_0.1 对 Ecal_perm_0.1 +0.730%、Ecal_match2_0.3 对 Ecal_diag_0.3 +2.407%、Ecal_match2_0.3 对 Ecal_perm_0.3 +1.337%。历史对应比较为 Ecal_match2_0.1 对 Ecal_diag_0.1 +0.979%、Ecal_match2_0.1 对 Ecal_perm_0.1 -1.364%、Ecal_match2_0.3 对 Ecal_diag_0.3 +1.386%、Ecal_match2_0.3 对 Ecal_perm_0.3 +0.208%。匹配的约束是起点处八批平均梯度范数，随训练变化的方向、裁剪、逐 lead 权重与路径仍可不同。初始范数匹配及所有后续探针见梯度表。

## 2. 历史信息对 S3 剩余误差的作用

历史输入的增益为IB 对 I0 +0.352%、IE 对 IB -0.471%，整体方向为部分支持。IB MSE 0.00010556，相对 Native +5.422%，相对 S3 +0.859%，相对自身对照 +0.643%。IE MSE 0.00010606，相对 Native +4.976%，相对 S3 +0.393%，相对自身对照 +0.248%。OOF 当前输出的物理 RMS 为 0.0032379，完整训练教师为 0.0031353。两者的剩余误差 RMS 分别为 0.012449 和 0.012168。冻结 S3 当前输出由已观测输入和 Native 决定，属于已有输入的表征。

## 3. 增量与同输入直接预测

历史队列中，逐组的点估计为 I0 对 D0 +0.207%、IB 对 DB +0.643%、IE 对 DE +0.248%。三项配对区间有 3 项包含零。三对 CNN 的初始权重和批次相同。D 的零输出从 Native 起步，I 的零增量从 S3 起步。

## 4. 增量机制

IB_match2 的历史增量分解为 Cδ 2.5131e-06、Uδ 3.7492e-06、Gδ 1.277e-06。对齐项 2Cδ 超过新增输出能量 Uδ。逐窗余弦均值为 0.069043，轨迹加权整场余弦为 0.12578。总修正分解 C、U、G 依次为 6.4757e-06、6.5381e-06、6.4133e-06。这两套分解衡量已发布修正的对齐与能量，对形成该修正的学习机制仍需结合配对对照。
相对 IB，变化来自对齐的部分为 2.2791e-06，来自新增修正能量变化的部分为 -1.9172e-06。

## 8. 自身反馈训练和运行

- MSE 使用 IE 配置。按参考训练固定运行、参考训练自身运行、自身训练固定运行、自身训练自身运行的顺序，物理 MSE 为 0.00011344、0.0001147、0.00011075、0.00011052。自身运行中改用自身训练的 MSE 改善为 +3.645%，训练与运行模式的差异差为 1.4945e-06，配对区间为 [-2.8179e-08, 3.736e-06]。联结窗口的历史反馈状态相对固定 S3 的平均 RMS 为 0.0021458 和 0.0020298，依次对应参考训练与自身训练。交互区间包含零，失配缓解仍待确认。
- aux 使用 IE_match2 配置。按参考训练固定运行、参考训练自身运行、自身训练固定运行、自身训练自身运行的顺序，物理 MSE 为 0.00011115、0.00011145、0.00011062、0.00011041。自身运行中改用自身训练的 MSE 改善为 +0.934%，训练与运行模式的差异差为 5.1297e-07，配对区间为 [-3.3284e-07, 1.8485e-06]。联结窗口的历史反馈状态相对固定 S3 的平均 RMS 为 0.0018558 和 0.001767，依次对应参考训练与自身训练。交互区间包含零，失配缓解仍待确认。
每条训练链监督三个窗口，反馈张量 detach。每个序列分支实际训练 5,000 次更新、15,000 次小批前向、5,000 次反向和 120,000 个窗口暴露，另借用 1,000 步单窗前缀。历史评价为 12 条轨迹，各连续 8 次发布，每次均有新观测。

## 11. 机制证据的边界

共享起点和配对批次控制了初始化与取样差异。等范数校准只控制起点处的平均幅度，后续梯度方向与裁剪可以分离。EN 的惩罚对象为新增修正，历史直接 E 的 EN 惩罚总修正。模式投影检验固定表示限制。时序映射含不同参数量，位置表达范围及有限样本所得的优化差异仍可能影响结果。

## 12. 路线取舍

后续机制确认应保持同输入 D 和初始等梯度对照。

按开发选定检查点，两队列相对各自对照均改善的投影或时间混合配置为 IB_lag。两队列的点估计均无改善时，降低配置的复验优先级。涉及 IE_K4, IE_K8, DE_K4, IB_reverse, IB_dual, IB_free。第 5 节另外给出了投影模型的固定步对照。

## 13. 论文主张与证据等级

本轮能报告单训练种子、固定主干、固定采样路径下的配对机制与工程结果。独立确认清单为空，跨初始化稳健性、未见主干工况泛化和长程运行稳定性均数据不足。开发选模后的区间仅作描述。历史队列的正向点估计不能替代独立复现。

## 14. 更简单的选择

S3 的端到端中位延迟为 8.31 ms，开发主规则所选 IB_match2 的端到端中位延迟为 8.72 ms。历史 S3 MSE 0.00010648，相对 Native +4.602%，相对 S3 +0.000%。在独立复验前保留 S3 作为运行默认项。
