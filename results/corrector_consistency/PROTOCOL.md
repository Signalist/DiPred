# DiPred 确定性整窗残差一致性消融

本轮限用旧 Corrector 缓存中历史起点 400 和 420 的 140 个整窗，保留原 46/12/12 轨迹划分，共 92/24/24 案例。输入为原历史真值 X 和缓存 32 成员的原尺度平均 P。以旧缓存身份、历史和目标张量哈希验证时间、成员和轨迹，保留原 20 帧目标和 32×64 网格。模型一次输出 20 帧修正，发布输入只使用 X 和 P。使用训练历史的 u/v 均值与总体标准差标准化 X、P 和标准化 MSE 评分。所有训练残差项独立采用训练真实残差的同一全局 RMS，包括方向的 u/v 两分量。

沿用窗口 Corrector 的卷积宽度 16、32、32 和 40 个输出通道。移除集合、坐标、记忆等槽，只用 X、P 的 80 个输入通道。输出层零初始化。A 为 MSE，B 为 MSE+方向，C 为 MSE+幅值，D 为 MSE+一阶平滑，E 为 MSE+二阶平滑，F 为 MSE+一阶真实差分匹配，G 为 MSE+方向+幅值+一阶平滑+二阶平滑。固定每项 λ=0.1。方向与幅值计算有效 3×3 邻域内的无向相邻边，每条等权。方向掩码要求两端真实无量纲幅值大于 0.05，按窗用有效边数归一化，空掩码贡献为零。方向范数分母下限为 0.01。幅值对所有有效网格边等权。离散差分仅沿物理时间帧。零残差比例按无量纲二维范数 ≤10⁻⁶ 定义。

固定种子 42、Adam 0.001、batch 8，有放回抽样。先训练 250 步公共 MSE，再将模型和 Adam 状态复制到 A–G，沿同一预生成的批次表继续到第 1000 步。所有组检查点为 0、250、500、750、1000，按开发集原尺度物理 MSE 选最小值，同分取早。先冻结所有选择，再评分测试，单独保留各组 1000 步结果。所有轨迹有两个同权窗口。主终点为相对 A 的完整 20 帧物理 MSE 改善百分比，由 10,000 次原轨迹配对 bootstrap 给出描述性 95% 区间。一次训练种子与已经重复使用的测试轨迹限制结论的适用范围。

高梯度与高原始残差区域分别按训练真实残差的局部前向空间梯度模和二维幅值的第 90 百分位定义。边界无效梯度以零贡献记录，梯度匹配与能量使用独立有效边。空间和时间差分与真值匹配、预测对真值余弦、内积、能量及恒等式同时输出。修正图固定开发集首条轨迹、历史起点 400、lead 20，时间图用网格 (16,32)。机制图使用第 1000 步权重。方向箭头用统一长度表示方向，颜色表示原幅度。

实际运行目录和命令见 run.log。复跑使用新目录，整理图表所需的单窗张量在运行中生成。

export PYTHONPATH="$PWD/../Forecast/Runtime/.deps"
set -o pipefail

output=$(mktemp -d .cache/corrector_consistency_replay.XXXXXX)
