# B/E 时空 Loss 优化固定协议

沿用已核验 RealPDE 822/24/24 三窗样本、冻结四次调用的单路径零噪声 P、相同 FP32/NCDHW、seed42、物理公共 RMS、原 6000 步批次索引及 B/E 输入槽。训练仅使用冻结 OOF 历史参考，开发/测试仅使用统一冻结 S3 参考。S3 和旧 B/E 保持权重不变。历史测试只在所有选择冻结后统一读取。

B/E 分别从原初始化完整重放纯 MSE。AdamW 初始 1e−3、6000 步余弦至 1e−6、weight_decay=1e−5、batch=8、裁剪 1。保存 1000 步模型、优化器、调度及 Python/NumPy/CPU/CUDA 随机状态，全部辅助臂从该状态及同一批次位置启动。先核验旧检查点与同数据开发评分，随后执行固定 0.1 全消融。所有其他训练步骤、残差单位、窗范围保持一致。逐臂选择最小原轨迹等权开发物理 MSE 的非零检查点，同分取早步。末步另外报告。共同 MSE 前缀作为合法选模候选，选到前缀意味着该配置没有贡献后续受约束更新。

固定 Loss 复用原一致性数学定义。每分支先执行五项 0.1 及原 JOINT；随后五项各试 0.01、1，复用 0 和 0.1。梯度在 1000、3000、6000 步纯 MSE 检查点，由三个预先固定的跨工况训练批计算。以 1000 步均范数配比保留固定 λ，ε=1e−12、λ≤100，相对范数≤1e−8 时记为不可校准。每项执行 ρ=0.1/0.3；可用预算优先覆盖全部核心臂和三种新增联合。重复权重按分支和实际权重去重复。原始边界扩展仅在核心预算有余且所选非零边界优于纯 MSE 时按开发改善排序进行。联合组依次评估单项最优权重组合、按实际联合向量范数校准至 ρ=0.3 的组合、最佳两项。每个核心训练运行至总步数 6000。核心最多 60 个新增臂含两次纯 MSE 重放；未经选定的历史测试不用于更改范围。

自主扩展优先检查方向关系匹配和二阶真值差分匹配。选择理由、假设、对照和结果单独记录。若最佳联合在开发集改善 >0.5%、至少 8/12 条改善且优于所有单项，补做必要的逐项移除。扩展最多 20 臂。固定开发残差场例为 26700_0.h5/400/lead 10。所有预测修正强度固定 1。精度主终点为开发物理 MSE；历史测试三个参照为 Native、S3 和各分支纯 MSE。区间为原轨迹配对 bootstrap 10,000 次。单种子、历史测试既往参与研究构成解释边界。图像位于仓库 `.User/corrector_spacetime_optimization/`。

## 复跑

```bash
source env.sh
export PYTHONPATH="$PWD/../Forecast/Runtime/.deps"
python -u -m research.corrector_spacetime_optimization.run
```

最佳两项组合按各约束的最佳非零尝试排序并保留两项，因而也能检验单独启用时未超过纯 MSE 的约束是否有联合贡献。调参联合仍允许单项权重为零。逐 lead 的一阶、二阶量按差分的最末帧对齐，前一帧、前两帧分别留空。相邻方向和幅值诊断使用原真值有效邻点掩码。
