# 冻结 DiPred：下一帧带符号残差预测实验

日期：2026-11-19。分支：`dynamics`。实验基于仓库提交 `ee69f8992df3b61c2082e385140dc57035207609`；交付提交号以 `git log -1 --format=%H` 及最终交付消息为准。

冻结原有权重与完整历史 20 帧联合预测未来 20 帧方式，只训练独立小残差网络。`e[t]=prediction[t]−truth[t]`，每个窗口每成员形成 19 对，目标为下一帧带符号残差。上一帧残差来自真值，因此结果限于离线诊断。

B−A 支持上一帧同格点带符号残差含有增量预测信息。C−B 支持此处 3×3 邻域在已知同格点残差后仍有增量价值。B/C 参数分别 1316/1332，C 多 16 个（1.2158%）；MLP、初始函数、训练抽样和优化预算相同。A 为 1250 个参数。容量近似匹配，不能将差异完全独立于这 16 个额外参数来解释。

打乱后的 B/C 分别为正确对应时 MSE 的约 2.87/3.42 倍，同一成员对应具有价值。打乱后仍优于 A，说明还存在轨迹和时刻共享的残差信息；不能把全部 B−A 收益归因于成员特有的连续性。打乱是输入扰动检查，不是重新训练的替代基线。

## 来源、划分与对齐

原始数据目录为 `DiPred+ResCrct/OLD/REALPDE/realpdebench-competition/data/train_real`，按原 HDF5 文件标识轨迹，读取 u/v 并空间下采样 `::2,::2` 至 32×64。原 manifest 为 `Workspace/runs/clean_direct20_20261107/manifest.json`。完整轨迹清单、工况、帧数、划分、源哈希和排除项见 [protocol.json](protocol.json)。

沿用原始 train/development/test 划分，共 46/12/12 条轨迹，所有窗口和 32 个成员均留在原始轨迹所属一侧。各轨迹历史起点为 400、420，目标为 420–439、440–459；每窗口 19 对。训练 55936、开发 14592、测试 14592 个两通道场对。`24150_20.h5` 仅 282 帧，排除；原 calibration 10 条轨迹不使用。

冻结模型使用 `reliability/checkpoints/current.pt` 中的 predictor，已与原 `Workspace/runs/physical20_augmented_dynamics_20261109/augmented_diffusion/model.pt` 的所有模型张量逐值核对一致。原权重和归一化不改；成员种子 500000–500031，四步去噪 99/66/33/0。

三个现有快照仅验流程：`13950_0.h5` 历史起点 0、`22875_0.h5` 起点 100、`3750_0.h5` 起点 200；对应目标起点 20、120、220。三个真值均与原始 HDF5 切片逐值一致，32 个成员全部 20 帧与原批次形状下的冻结模型重放逐值一致，最大差异均为 **0**。这些快照窗口不用于训练、选模或本轮评分；[alignment.json](alignment.json) 保存每对帧索引与成员种子。

现有完整成员输出只有三个快照；大部分历史缓存仅有均值、标准差和评分，无法恢复成员残差。本次补算正式窗口的完整成员输出，缓存位于 `Workspace/runs/residual_dynamics_20261119`，之后复跑优先复用。[cache_manifest.json](cache_manifest.json) 保存六个缓存分片及历史/真值切片哈希。

## 结论范围与数据缺口

现有独立 HDF5 轨迹足够完成本轮划分，没有将三个快照拆成伪独立训练/测试。但测试侧只有 12 条轨迹、3 个 Re 工况，而且这些历史数据已反复用于研究；轨迹 bootstrap 不能覆盖工况之间相关性、超参数选择历史或训练随机性。仍缺未参与既往研究的新独立确认轨迹、更多独立工况和时间段，以及多个训练随机种子。

本轮只使用两个后续窗口、单个训练种子和一个小型邻域结构，不能概括所有残差传播模型。使用真实上一帧残差的收益不代表无真值在线预测收益，也不证明 C 恢复了物理速度或真实误差输运机制。原始数据的 SI 单位尚未独立确认。
