# 同物理时刻重启的输入归因与冻结采样器JVP：固定协议

起始实际及参考HEAD=5064fa8c483fdc6df8e8d3bfba7a110d388a54bc，dynamics。任务完整文本见TASK.md。本协议和config.json先于新的开发/测试评分，写后不改。旧native_restart_consistency、nonlinear_parameterization_control及证据台账只读，不重跑旧训练或重新寻找相容性现象。用户要求交付后push。

主清单为原development/test各12条轨迹、400/420历史起点、repeat0/1、k2/5/10、M32，完全复用原A/B/C/S缓存、成员顺序和子种子（根202611211/202611212及原SHA256派生）。每个k的子噪声z_i从旧calls恢复并重新生成初始噪声，逐成员hash必须等于旧记录。R/M/S之间复用同一z_i，不同i与父A之间仍独立。这是耦合输入干预，不是同一物理随机轨迹；不计算R/S或M/S的旧独立样本ED_U。

对H[C,20,H,W]，H_i=concat(H[:,k:],A_i[:,:k])；H_M使用32个父前缀的逐点均值；H_R使用只读接口返回的前k帧oracle标签。接口必须只取[start+20,start+20+k)，拒绝全20帧标签；Y[:,k:]只有在R/M生成后才读取评分。三组同一20帧历史长度、同一物理重启点、同一冻结归一化和主干。完整生成20帧，只比较前L=20−k帧，对齐原B的第k+1…20帧。R含新真实观测，仅离线oracle；M是均值前缀干预，不替代父混合分布，不以M好为由丢弃不确定性。

新增18432条主路径上限：24×2窗口×2重复×3k×32×2新组(R/M)。S完全复用；A/B/C及其已有同尾段评分也只读复用。每个新缓存保存R/M比较尾段、HR/HM、旧缓存身份、种子/初始噪声hash、输出hash。正式顺序按原manifest筛选development、test，400再420、repeat0再1、原轨迹清单顺序，每组内k2/5/10。

定义标准化输出响应D=S−R、Dm=M−R、Dd=S−M（均除训练通道std）。报告逐成员及按成员/像素平均的RMS、平方量、2<Dm,Dd>，核验D=Dm+Dd及D²=Dm²+Dd²+交叉项。RMS汇总是各预设块RMS的均值，平方量另报；不可将非正交平方比当独立解释比例。Dd包含非线性、有限样本及共享均值的作用，不称纯Jensen项。另报告ensemble-mean响应幅度，与全成员响应区分。

MSE符号分解按原尺度及标准化分别计算：d=mean(S)−mean(R)，eR=mean(R)−Y_tail；MSE_S−MSE_R=2mean(eR*d)+mean(d²)。交叉项保留符号，幅度不等于损害。同时比较R/M/S的CRPS、全尾段RMS ES、原尺度和标准化均值MSE、逐点方差、90%宽度、逐路径先时间平均的CRPS；旧B为参考，不把R优于B称为原20→20可部署收益。按k、Re、u/v、lead、原轨迹完整报告，R不优于B也不能单独归因历史截断。

可微入口在新目录实现原四步，不能调用旧no_grad采样函数。主干eval且requires_grad=False，history保留梯度，初始噪声固定，不detach中间状态；直接调用原DynamicsNet保留history.diff和scale导数。JVP使用torch.autograd.functional.jvp（双反向自动微分），所有去噪步骤保持完整计算图。标准化历史/输出坐标下e=Hi_norm−HR_norm，只在最后k帧非零。dlin=J F(HR_norm,z)e；真实响应由原S与新R缓存比较，不缩小主扰动。

固定JVP清单：全部24条development/test轨迹，start400/repeat0，k2/5/10，成员0/8/16/24；共288个方向，batch4计算，相互不跨样本。每个方向另算lambda=.5；不以4成员计算概率评分。保存原始输入全20帧RMS、最后k帧RMS，线性/有限响应RMS、误差RMS、相对误差、方向余弦、线性及真实响应增益；full与half分别报告。方向或响应RMS<1e-8标为near_zero，余弦和相对指标记空而不是捏造0；绝对指标仍保留。lambda0/1可微入口与R/S物理输出复现，固定maxabs容差2e-6。

预检仅原清单前两条训练轨迹10125_0.h5、10125_10.h5，start400/repeat0，k2/5/10；新入口对32成员旧S逐值核验maxabs≤2e-6。JVP有限差分使用固定成员0/16，方向取实际e并标准化为全历史单位RMS；中心差分epsilon={.01,.003,.001}，全部误差保留。预先判定：每方向较小两epsilon中至少一个相对误差≤.03且余弦≥.995；最小的较小步长误差≤大步长误差×1.25+.001，允许float32舍入平台；梯度有限且非零。失败则停止JVP科学结论，继续可执行主对照并记录数值阻碍，不放宽容差。数值单位方向核验不是全幅准确性的证据。预检包含未来尾段污染不改变R/M/S输入与输出、增量通道梯度、四步标签顺序、固定噪声、响应恒等及有符号MSE恒等测试。

执行前冻结代码/config/协议/预检和旧缓存索引hash。正式新增R/M只在oracle前缀揭示后生成，剩余真值在生成保存后才评分；事件日志区分oracle前缀与未来尾段。JVP/半剂量路径、预检和任何缓存恢复单独计成本，不混进主18432路径或部署延迟。主干调用数分别记实际批前向、样本等效前向；JVP额外两次反向也记数，不把反向成本当普通推理。

固定一块A100、主对照+JVP总两小时，新增缓存≤12GiB；预检成本另列，若缺缓存只按原身份恢复并单列成本，不新增随机样本。任何预算/数据阻碍按原顺序停止并明确未完成清单，不换子集。没有训练、记忆头、一致性/Jacobian正则或超参搜索。

所有推断每条原轨迹先平均窗口/重复/成员方向，再按轨迹配对bootstrap10000次seed123。三k分别报告，95%及Bonferroni98.333%区间都给；各Re另报，承认测试只有3组。主质量对比S−R、M−R、S−M、R−B，其他配对作为描述。A/B/C/D解释可以并存：比较响应平方量及带符号交叉项、质量代价、JVP全幅误差和半剂量变化，不强制唯一原因。描述“全幅局部线性可信”预设为轨迹平均相对误差≤.2且余弦≥.95；否则不称全幅准确，绝不靠半剂量代替。该标准仅解释工具，不选模型。均值项主导只指其平方量通常更大且差的轨迹区间为正，交叉项和成员项必须完整保留。
