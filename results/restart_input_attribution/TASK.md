H_M = concat(H[:,k:], mean_i(A_i[:,:k]))：预测均值前缀。

所有组丢弃同样最早k帧、使用同一重启物理时刻及同样20帧长度。

【3. 主要量与可解释分解】
对第i个固定子噪声，F_i代表冻结四步采样器截取后的同一尾段：
Delta_i = F_i(H_i) - F_i(H_R)
Delta_mean_i = F_i(H_M) - F_i(H_R)
Delta_member_i = F_i(H_i) - F_i(H_M)
核验Delta = Delta_mean + Delta_member。
报告三者标准化RMS与平方量，并保留2<Delta_mean,Delta_member>。
这是模型响应分解，不是正交方差分解；不能把比值当独立解释比例。
Delta_member含非线性、有限样本和共用预测均值的作用，不自动称纯Jensen项。

令mu_S、mu_R为对应集合均值，d=mu_S-mu_R，e_R=mu_R-Y_tail：
核验 MSE_S-MSE_R = 2<e_R,d> + ||d||^2（按完整尾段维度平均）。
保留符号，不能把所有响应幅度都称“损害”；模型错误可能抵消。

R/M/S分别报告完整CRPS、ES、原尺度/标准化均值MSE、variance、90%宽度、
每条路径先做时间平均再评价的CRPS。
分k、Re、u/v、lead与原轨迹报告。R只是新的观测条件诊断；
R优于B不属于原20→20任务的可部署收益，R不优于B也不能单独证明截断有害。
不从R/M/S结果直接判定20帧是否Markov充分；该问题本轮可能仍无法识别。

【4. JVP：测冻结生成器的输入误差响应，不训练正则】
native core.sample_noise、generate和原rollout有no_grad装饰。
在新目录实现完整四步可微入口：权重eval且requires_grad=False，历史保留梯度，
固定噪声，不通过旧no_grad函数，不detach中间状态，不截断任何去噪步。
先与原入口对同历史、同噪声逐值核验；容差在预检前固定，不随结果扩大。
history.diff及其scale归一化必须保留原定义并正常传导。不可把派生增量通道单独冻结。
整个JVP描述学习到的采样器，不是PDE Jacobian，也不是把去噪时间当物理时间。

主JVP在标准化的历史/输出坐标中进行：
e_i = H_i - H_R（只在新增前缀段非零），
d_lin_i = J_H F(H_R,z_i) e_i。
比较d_lin与真实有限响应Delta，报告绝对误差、相对误差、
方向余弦（近零方向另记）、响应增益，并保留实际扰动幅度。
可记录均值偏差m=H_M-H_R和成员偏离delta=H_i-H_M，但不额外训练算子。

固定JVP子集：所有development/test原轨迹，start400、repeat0，
k={2,5,10}，成员ID={0,8,16,24}，不选误差大或结果好看的成员。
在同一固定子集额外计算F(H_R+0.5e_i,z_i)，与lambda=0和1比较；
只作非线性剂量诊断，不用这4成员集合代替32成员主评分。
有限差分核验只用固定训练预检：先把方向标准化为单位RMS，
用预设小步长集合{1e-2,3e-3,1e-3}的中心差分检查JVP收敛和数值精度。
数值核验不通过时记录并停止JVP结论，不能将零梯度或数值问题解释成模型稳定。
全幅线性近似不准时如实报告，不通过缩小扰动来伪装其对真实误差也准确。
