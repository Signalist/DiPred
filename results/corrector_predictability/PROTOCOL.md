# 冻结 DiPred 的残差可预测性与对齐

使用原 RealPDE 46/12/12 条实测轨迹，完整 20 帧历史预测 20 帧未来。所有 P 均为通过既有 SHA-256 和时间身份审计的同一 32 成员原尺度集合均值。Small 包含训练起点 400/420 的 92 窗，Expanded 加入 440/460 后为 183 窗。仅保留真实帧完整案例。开发与测试均为 400/420 的 24 窗。共享上一轮 Small 训练数据算出的输入通道均值、标准差、公共残差 RMS 及区域诊断阈值。发布仅使用 X/P 和可选 F。

## 阶段与选择

- **Stage 0** 固定上一轮 A/B/G 的 1000 步权重。开发集拟合全局 α 并投影到 [0,1]，记录固定 α 网格 0、0.05、0.1、0.2、0.5、1。测试比较冻结 α、原强度和共用 Native。读取测试标签的 α 标为 Oracle，报告 [0,1] 和无约束的线性最优值，分别按全局、通道、lead、轨迹及窗拟合。
- **Stage 1** Small 和 Expanded 各训练 42/43/44 三种子。旧 16,504 参数 XP，Adam 0.001、batch 8、1000 步。每步有放回均匀采样原轨迹，再均匀抽该轨迹合法窗。
- **Stage 2** Expanded 上比较 XP-zero、XPF、XP-active-control。维持相同网络与逐种子初始化和采样。F 为独立零初始噪声路径第 0 标签调用的 up2 输出 48 个通道。它没有原 32 成员和平均 P 的隐状态身份。沿用原主干归一化。F 使用训练通道均值与总体标准差，代理固定从标准化 X、P 各取 24 个展平通道，第 i 项为向下取整 i×39/23。旧 XPF 产物的特征来源或任务无法匹配冻结规格。训练和开发 F 可先缓存。测试 F 必须在全部决策冻结后计算。
- **Stage 3** 对每个 Stage 1/2 模型族检查三种子平均开发改善 ≥0.5%、至少两个非零正收益种子、至少 8/12 条轨迹改善。若多个通过，选三种子开发平均改善最高者，名称字典序破同分。每个种子共享 250 步 MSE 模型及 Adam 状态后分支四组至 1000 步。λ=0.1。邻点方向一致、邻点真实关系匹配、点对点真值对齐均使用真实幅度 >0.05 掩码与 0.01 范数下限。点对点采用有效位置等权。无候选通过则只做数值核验。

各训练保留 0/50/100/250/500/750/1000 步。每一步都比较 α=0、1、开发拟合三个策略。按开发全集原尺度 MSE 排序，同分优先早步再较小 α。独立报告选中策略、1000 步开发拟合 α 和 1000 步 α=1。训练学习曲线用各组固定训练集全窗。主终点为冻结选模后相对 Native 的完整原尺度测试 MSE。所有选择与固定开发示例（开发清单首窗，lead 20，种子 42）在读取测试标签前写入 FROZEN。方向示例采用第 1000 步权重。按原轨迹先平均窗口，再平均种子，轨迹配对 10,000 次得到描述性 95% 区间。旧测试为探索性。

## 复跑

从 Corrector 工作树执行。指定新目录与 F 缓存可完整复跑。大特征缓存留在本地。

~~~bash
source env.sh
export PYTHONPATH="$PWD/../Forecast/Runtime/.deps"
set -o pipefail
out=$(mktemp -d .cache/corrector_predictability_replay.XXXXXX)
python -u -m research.corrector_predictability.run --out "$out" --cache "$out/features" 2>&1 | tee "$out/run.log"
python -m research.corrector_predictability.plot "$out"
~~~
