# 统一最终评分的非线性直接预测与传播参数化

九次正式训练和冻结后的探索性评价均已完成，当前证据不支持固定局部传播结构具有稳定增量价值。T_local 的科学候选在开发集有很小的平均 CRPS 改善，但旧测试窗口退步；extension 的小幅改善区间跨零，且 CRPS 点估计不优于 T_diag。改善集中于 Re 3750，其他两个 Re 退步，原尺度与标准化整体 MSE 也存在代价。本轮按协议归档当前固定算子＋共同平移支线，不追加配置、loss、特征、训练或 Diffusion 改动；结论不能外推为所有非线性方法无效。

**执行完成与效果支持分开。** 资源和实现没有遗留阻碍；完成九次×1000步及全部统计，不等于效果成立。旧 pilot 的 gate=false、六次岭回归、零次神经训练及全部旧结果保持不变。本轮是独立探索协议，不是旧 stage_b 的续跑。实际起始 HEAD 为 a7b7f50caf5b75b2945cc6c8f2ce0076dd77c09f，分支 dynamics。用户已有未跟踪修改保留。交付提交号以本目录的 Git 历史和最终回复为准。
