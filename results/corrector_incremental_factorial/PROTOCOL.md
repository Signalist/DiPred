# DiPred 增量纠错全因子协议

主队列采用 2×2×2 配对设计，因素为增量参数化、真实历史残差和 TM2。八格共享单路径冻结 Native、S3 表征、轨迹等权批次与训练参数。配对增量和直接模型共享初始化，零输出分别回到 S3 和 Native。四个 TM2 主臂使用上一轮 IB_match2 的实际 λ。各辅助臂从本支第 1000 步完整 MSE 状态接续。主比较用固定 6000 步，开发选中检查点另报。保留旧权重、教师记录和研究产物。

主队列使用上一轮 822 训练窗和 24 开发窗。训练使用合法折外 S3，开发和历史使用全训练 S3。所有臂固定 seed42、FP32 NCDHW、三层 width32 CNN、AdamW、批次 8、梯度裁剪 1。训练日程、尺度和检查点沿用已签名记录。第 0 步保留作安全参照。逐轨迹等权物理 MSE 选模，同分取较早检查点。P1 比较 IB_match2 与 I0_match2，P2 比较 IB_match2 与 DB_match2，P3 比较四组 TM2 与自身 MSE，P4 比较开发预选模型与 S3。

用预定 Re 分层八批估计初始梯度，若三个新增主臂中任一个在固定 λ 下的辅助对主梯度比例偏离 0.3 超过相对 25%，补齐三个分别校准到 0.3 的辅助臂。校准结果单列。若 I0_match2 固定步优于 I0 且开发物理 MSE 不超过 IB_match2 的 100.5%，为 I0 补充各一组等初始强度 TM1 和 EN。若 IB_match2 固定步相对 IB 的开发改善至少 0.5%，以预定 IB 结构补充等初始强度 DIAG 和 PERM。首要解释缺口由这些控制覆盖。其他扩展需在冻结前依据开发证据登记，按共享预算决定。

输入干预仅用于回顾性诊断。开发固定后在允许的评价队列沿用规则。按 Re 对合法历史输入循环置换，优先跨轨迹。反转时间只改变历史通道。边界保留和屏蔽采用末 5 帧与末 10 帧。空间置换以 seed42 在 32×64 平面生成一次排列，同一排列应用到每帧和两个通道。另逐帧置零记录 20×20 响应。固定物理场案例沿用 26700_0.h5、start 400、lead 10。

新增主训练及开发诊断结束后冻结候选、教师和验证配置。冻结后按原清单重建三个隔离工况的八格矩阵，目标为 15 次新增复验。历史 24 窗、连续 96 窗和后 48 窗为既有队列。各工况压力测试沿用相应隔离 S3 和训练尺度，冻结 DiPred 曾见过留出轨迹。配对 bootstrap 以轨迹为单位，10,000 次，seed42。因子主效应为相应四个配对下降量的平均，二阶为条件差分的平均，三阶为两条件的二阶差分之差。正值约定为误差下降或误差下降增加。图表采用实测数据。
