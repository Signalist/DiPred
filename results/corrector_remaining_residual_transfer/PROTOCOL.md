# 冻结 S3 下的跨窗口剩余残差传导

所有样本沿用已登记的 20 帧输入和 20 帧输出。DiPred 冻结，每次发布使用一条零初始噪声、四次去噪的预测路径。S3 冻结。训练使用同一轨迹的合法单个折外教师计算当前和历史 S3，开发与历史使用完整训练 S3，外层使用同工况隔离教师。历史真实残差 R、历史 S3 预测残差 P 和历史剩余残差 E 在上一个观测窗到达后计算，E=R−P。当前目标只用于训练监督或评分。

六结构输入在共同 8 通道后依次添加 I0 无额外输入、IB R、IC P、ID E、IE R/P、IF R/E。公共训练尺度相同，三层 width32 FP32 NCDHW CNN。IE 和 IF 的可用信息代数等价。使用 seed42、AdamW、初始学习率 0.001 余弦至 0.000001、权重衰减 0.00001、批次 8、裁剪 1 及原轨迹等权采样计划。MSE、TM1、TM2 和 EN 共 24 格，6000 步主分析。后两种时间辅助项分别取 19 和 18 个有效差分上的均值，EN 仅惩罚增量。辅助臂使用共同 1000 步完整状态与训练侧固定八批，初始 ρ=0.3。旧校准若批次、来源、优化器状态及协议均一致，允许实测初始 ρ 在 0.3 的 0.000001 内复用已登记系数，并保留实际系数。有开发重放浮点差异时记录并重新评分，完整训练状态原样借用。

共同实际权重对照为 IB 和 ID 的 TM1 使用上一轮 I0 TM1 的实际权重，ID TM2 使用固定 3.141176237928434，并核验旧 I0 和 IB 固定权重锚点。另对 I0、IB、ID 在 250 步重校准 ρ=0.3 启用 TM1 和 EN，共六臂。报告 500、1000、6000 与开发最优检查点，历史与留出均按发展阶段冻结清单使用这些步数。主要固定步开发选择与开发早停选择分别冻结，同分优先较早步。主选择在核心、早期和已登记的时间映射配置内进行。P1 为 ID 对同 Loss IB，P2 为 ID 对同 Loss I0，P3 为 ID 的辅助目标对 ID-MSE，P4 为开发候选对 S3，P5 为提前启用对对应纯 MSE 开发早停。轨迹级配对 bootstrap 使用 10,000 次 seed42 抽样。

Stage 0 仅使用训练轨迹的折外残差。按类型、Re、通道和空间位置计算相关，时间矩阵按两个 lead 及物理间隔 20+j−i 登记。ID 额外比较固定末帧广播与恒等初始化 Lag 两个纯 MSE 方案。若其中开发固定步 MSE 较原 ID 至少改善 0.5%，只对优胜映射补做 TM1。保持外层预算优先。早期辅助手段仅在固定步开发 MSE 达到正式矩阵最优时，选一个外层补充。空间/时间干预只在冻结后进行，保留原始、置零、固定同 Re 跨轨迹置换、反转、保留/屏蔽末 5/10 帧、空间置换和逐帧置零。组合模型记录联合与单槽干预。

三个工况沿用 Re=17812、25482、8863 的隔离教师，每个工况固定主队列实际权重核验 I0、IB、ID 的 12 格。历史 24、96、48 和 168 窗全部为既有评价队列，效果之外核查新的合法时段与独立身份。固定物理场采用 26700_0.h5、起点 400、当前 lead10，历史与当前共同物理色标。冻结后只作评价和审计。默认运行模型的推荐结合历史区间、时间外推、工况和成本。没有足够证据时继续保留冻结 S3。

## 复现

```bash
source env.sh
export PYTHONPATH="$PWD/../Forecast/Runtime/.deps"
python -u -m research.corrector_remaining_residual_transfer.run all
```

发布接口使用 `research.corrector_remaining_residual_transfer.publication.load_publisher` 加载指定模型和检查点。输入为一个 GPU FP32 观测窗，形状为 `[1, 2, 20, 32, 64]`。调用 `issue` 时，同时返回最终预测、本窗 Native 及本窗 S3 修正，后两项可在下一窗观测到达后作为缓存使用。无缓存时传入前一个观测窗以重算所需历史量。
