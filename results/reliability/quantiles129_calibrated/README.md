XPF129 在线分位积分近似 CRPS 为 **0.081449**，129 个分位的平均绝对覆盖误差为 **0.856 个百分点**。该 CRPS 在分位点之间使用梯形数值积分，在 0%–0.25% 和 99.75%–100% 采取常数分位尾部假设；它与直接根据真实样本计算的经验 CRPS 是不同的数值估计。Fair CRPS 使用 K(K−1) 归一化；由于样本共享从同一集合得到的在线尺度，不能直接宣称其对理想独立分布 CRPS 无偏。

8/32 各自使用原方法的在线风险记忆；真实未来完整揭示后才更新。对实际每条路径执行 `P + (sample - P) * (calibrated_radius / raw_gaussian_proxy_radius)`，然后以这些样本计算 CRPS。由于有限样本的经验分位数不同于 `P ± 1.645 × 样本标准差`，高斯代理区间的覆盖不代表路径经验区间的覆盖。8 条为 32 条的前 8 条，但各自使用独立校准尺度。XPF 的 129 个分位同时应用基于 5%/95% 的在线仿射尺度，不是分别校准 129 个点，无全场、整段或分布外覆盖保证。

`snapshot64.npz` 是测试首窗口两个轨迹、每轨迹每通道 64 个对齐位置的标准化真实值、预测与 8/32 样本和 129 分位快照；其中分位数是相对点预测的残差。它仅供核验，不能重算完整测试集逐点分数。完整评估的聚合表涵盖每轨迹 42 个窗口；开发集与测试集各 12 条轨迹。原始逐窗口大文件保留在实验工作目录而未上传。
