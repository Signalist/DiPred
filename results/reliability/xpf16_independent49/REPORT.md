# 49 个独立 XPF16 双分位模型与 8/32/256 样本对照

本报告仅在 49 个模型、全部评估和独立审计完成后生成。每个模型输入 16 维特征，只输出两个分位数；不是 98 输出联合网络。四步 DiPred 一次预测完整未来 20 帧。

测试集为历史上多次使用过的轨迹；虽然本轮训练、校准、开发和测试按轨迹分离，不能把它称为全新盲测。报告为探索性，覆盖率是逐点边际指标。

独立模型拼接后，测试第 2–42 个窗口中，至少发生一次跨模型相邻分位交叉的位置比例：Raw 41.57%，Online 25.23%；单调重排后为 0%。Q49 的在线上下界在全部 42 个窗口有 21.80% 的位置发生交叉并被投影到中点，窄区间结果需要谨慎解释。

完整 49×4×Raw/Online 结果见 `macro49.csv`；逐 Re、u/v、预测帧结果见 `test_group_lead.csv`，逐轨迹、逐窗口结果见分片 CSV。

49 个独立头的 98 个点在概率轴上排列；50% 为 49%/51% 的插值。CRPS 采用相邻百分位的梯形积分，0%–1% 与 99%–100% 使用常数分位尾部假设；独立模型交叉时分别报告原值和单调重排结果。PIT 为插值后的分位函数反演，并在分布原子处采用中点。8/32/256 的经验样本 CRPS 与 XPF 分位积分 CRPS 是不同估计量。

随机样本以各自的 90% 代理区间在线尺度变换后再计算经验分位；这不保证任意概率水平的覆盖。8/32 样本尤其无法稳定解析极端尾部。XPF 每组使用独立的双尾在线状态，只在完整窗口揭示后更新。

图表提供 PNG 与 PDF，详见 `figures/`。逐窗口数据仅保存预测指标而非全部原始物理场。

逐窗口及逐帧分组数据位于 `split_data/`；运行 `python research/xpf16_independent49/restore_result_parts.py results/reliability/xpf16_independent49 --output-directory reconstructed` 可拼接并核验 SHA-256。

可复用接口：`from reliability.independent49_predict import XPFIndependentPredictor`。构造函数传入网格几何、`weights/`、`initial_offsets.pt` 和所需 levels；依次调用 `predict(history)` 与 `reveal(full20_truth)`。levels 默认为全部 49 个，单组可指定如 `[5]`。
