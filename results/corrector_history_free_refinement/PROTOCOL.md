# DiPred 无历史残差增量纠错

沿用上一轮 822/24/24 个训练、开发、历史窗口及 46/12/12 条轨迹。Native 固定为单条零初始噪声路径，四次去噪。训练使用轨迹级折外 S3，开发和历史使用完整训练 S3。延用原物理尺度、批次计划、seed42、FP32 与 I0 三层 width32 网络。I0 发布只读取当前观测窗、当前 Native 与当前 S3。

M0 使用最终误差的 MSE。TM1/TM2 分别附加最终误差沿时间的 19/18 个有效差分平方均值。EN 只惩罚归一化增量平方。三类辅助目标从同一个 I0 纯 MSE 第 1000 步完整状态继续，各用训练侧固定八批校准至 ρ=0.1、0.3，共计 6000 步。使用 AdamW、批次 8、梯度裁剪 1、学习率从 0.001 余弦降至 0.000001、权重衰减 0.00001。原固定 λ 的 I0_match2 单列。

主选模根据固定 6000 步轨迹等权物理 MSE，按家族各选一个候选。开发最优检查点另报，若位于共同前缀，标记辅助训练尚未产生额外收益。P1 比较最优 I0 与 S3，P2 比较最优 TM2 与最优 TM1，P3 比较最优时间目标与最优 EN。全部区间按轨迹配对重抽样 10000 次。历史队列参与过研究。

独立 S3_extra_MSE 从 S3 第 6000 步权重开始，在复制模型上重新初始化 AdamW 和随机状态，以 0.0003 到 0.000001 的余弦日程续训 6000 步。监督为原始 Native 残差。若固定步开发 MSE 不超过最佳 I0 的 100.5%，进入三个隔离工况对照。同工况的额外训练从该工况自己的完整子训练 S3 出发。

冻结前可用训练能量匹配补充一次 EN。只有当最佳时间目标与最佳 EN 的训练增量能量相差超过 20%，且两档标准 EN 的训练能量正好夹住时间目标时，按对数空间插值估计一个 beta。该配置用于机制诊断。其余可选扩展按开发阶段证据与预算决定。冻结后按原规则评分历史 24 窗、连续 96 窗和较晚 48 窗。按原连续队列最后一个起点加 20，登记每条历史轨迹随后所有完整窗口，至起点 820，共 168 个。同一轨迹的扩展时间段单列。外层沿用三个工况隔离教师与各自训练尺度，固定实际权重及 6000 步。测量分段和端到端单窗口成本。场图固定使用 26700_0.h5、start 400、lead 10。

运行建议另参考部署适用性。在本轮描述性证据下，只有当固定步 I0 候选优于开发 S3、历史 P1 的轨迹配对区间下界为正、三个工况和额外 168 窗的改善点估计均为正时，才建议将该候选作为默认运行方案。其余情况下默认保留 S3，开发预选的 I0 继续用于独立复验。

## 复现

```bash
source env.sh
export PYTHONPATH="$PWD/../Forecast/Runtime/.deps"
python -u -m research.corrector_history_free_refinement.run all
```

单窗口发布接口为 `research.corrector_history_free_refinement.deploy.load_publisher()`。加载后传入 GPU 上形状为 `[1, 2, 20, 32, 64]` 的 FP32 物理观测张量。接口返回 20 帧物理预测。
