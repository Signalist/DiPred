# 冻结 DiPred 的带符号残差动力学诊断

本实验只训练独立残差网络，预测 `e[t+1]`，其中 `e[t] = DiPred_prediction[t] - truth[t]`。
上一帧残差使用真值计算，属于离线诊断；没有将预测的残差递归输入下一步，也没有修改或重训 DiPred。
实际结果见 [结果说明](../../results/residual_dynamics/README.md)。

## 复跑

当前工作区仓库入口：`DiPred+ResCrct/Workspace/github/DiPred`。需要原有 CUDA PyTorch、NumPy、h5py；本机 h5py 需由 `Workspace/env.sh` 提供。

从仓库根目录执行：

```bash
source ../../env.sh
export TORCH_ALLOW_TF32_CUBLAS_OVERRIDE=0
python research/residual_dynamics/run.py all
python research/residual_dynamics/verify.py --check-cache
```

`all` 顺序执行 `audit`、`cache`、`fit`、`score`。任一对齐断言失败会立即终止，不训练受影响数据。
缓存位于 `Workspace/runs/residual_dynamics_20261119`，身份一致时优先复用。结果位于 `results/residual_dynamics`。
完整成员预测的既有缓存未找到，原有均值、标准差、CRPS 无法恢复带成员身份的残差，因此首次运行补算 6 个分片。
重跑只训练和评分可分别使用 `fit`、`score`。`verify.py` 不训练，会重算表格汇总、检查轨迹隔离、初始函数、打乱边界和冻结权重哈希。

在另外的结果目录复现，避免覆盖发布结果：

```bash
python research/residual_dynamics/run.py all --out ../../runs/residual_dynamics_replay
python research/residual_dynamics/verify.py --out ../../runs/residual_dynamics_replay --check-cache
```

位置可由 `--workspace`、`--data`、`--cache`、`--out` 指定。代码只读本地数据，不下载数据。
`--workspace` 下需有原始 `runs/clean_direct20_20261107/manifest.json`、`runs/physical20_augmented_dynamics_20261109/augmented_diffusion/model.pt` 和 `runs/compact_test_distribution_20261111` 三个快照。
`--data` 指向 HDF5 原始轨迹目录。完整路径和 SHA-256 记录在结果 JSON 中。

## 对齐与冻结

三个快照仅验流程：`13950_0.h5` 的历史起点 0、`22875_0.h5` 的 100、`3750_0.h5` 的 200。
先以原 HDF5 的 `u/v[target_start:target_start+20, ::2, ::2]` 核对真值，再以原测试批次顺序、原 12 轨迹批次形状重放种子 500000–500031。
随机噪声与批次形状有关，不能把单轨迹调用误当成原批次中某成员的重现。
每个种子只初始化一次完整 `[B,2,20,32,64]` 状态，四次去噪 `99→66→33→0` 始终联合处理全部 20 帧。
验证全部 32 个成员全部 20 帧，不通过分位排序、逐帧最近邻或相关性猜测成员身份。
同一轨迹、窗口、成员内的相邻帧构造 19 对，禁止跨窗口的第 20→1 帧拼接。

使用仓库 `reliability/checkpoints/current.pt` 中的 `predictor` 和归一化，逐张量核对其与原 `augmented_diffusion/model.pt` 完全一致。
调用 `eval().requires_grad_(False)`，只在无梯度阶段补算；训练阶段不加载 DiPred。
正式缓存维度为 `[trajectory, member, channel, frame, y, x]`，保存原数据尺度的残差及历史/目标切片 SHA-256。

## A/B/C 与容量控制

空间位置为网格索引归一化后的 `x/y∈[-1,1]`，步长为目标帧 `2..20`，归一化至 `[-1,1]`。不输入工况、速度、未来预测场或历史场。

| 组别 | 输入和运算 | 参数 |
|---|---|---:|
| A | x/y/目标步长，逐点 MLP `3→32→32→2` | 1250 |
| B | 另加上一帧同格点两通道带符号残差；逐通道 1×1 混合、逐点 MLP `5→32→32→2`，保留本地残差直连 | 1316 |
| C | 同 B，混合层改为逐通道 3×3，允许相邻格点残差；保留本地残差直连 | 1332 |

B/C 多 16 参数，相对 B 增加 1.2158%。两者 MLP 权重、初始函数、数据抽样序列完全一致；混合权重均从 0 开始。
所有 MLP 层都是 1×1 卷积，没有空间归一化、全局统计或时间卷积。B 无法读相邻格点，C 的残差感受野严格为上一帧 3×3，边界用复制填充。
B 可学习改变本地残差幅度、符号和通道组合；C 保留这些能力，并增加邻域线性混合。
这是小容量邻域检验，不能据此断言所有空间传播模型的价值。

## 训练和评分

沿用原 manifest 的轨迹划分，不随机拆窗口或成员。正式窗口历史起点为 400、420，目标帧分别为 420–439、440–459。
46 条训练轨迹满足完整帧要求，12 条开发、12 条测试；原 10 条校准轨迹不使用。
原训练划分中只有 282 帧的一条轨迹排除，身份详见 `protocol.json`。
每轨迹 `2窗口 × 32成员 × 19对 = 1216` 个相邻帧场对；不是 1216 条独立轨迹。
总共训练 55936、开发 14592、测试 14592 个场对，每个场对有两通道和 32×64 网格。

训练只使用一个训练集残差 RMS 标量缩放输入/目标，因此优化目标仍与原尺度两通道均匀 MSE 成正比，不改变通道相对权重。
每组固定 2000 步 Adam，学习率 .001，每批 16 个独立抽样的轨迹/窗口/成员/相邻帧场对。
训练种子 42、批次种子 20261119。每 250 步及终点在开发集评估，以最低开发集轨迹宏平均 MSE 选择 checkpoint；不根据测试结果改选。
只有一个训练种子，没有进行超参扫描。

先在每条原始轨迹内均匀平均两个窗口、全部成员、19 对、空间和两通道，得到该轨迹原尺度 MSE；再对轨迹等权平均。
同时报告 u/v 分通道 MSE。原数据尺度的 SI 单位没有独立确认，不将其称为已确认的物理 SI 单位。
B−A 检查上一帧残差的增量预测信息；C−B 检查在本地残差已知时邻域的增量预测价值。
差值置信区间仅对测试侧原轨迹做配对 bootstrap（10000 次），不将成员、网格或窗口当独立重复。

B/C 成员打乱在每条轨迹、每个窗口、每个时刻各生成一个 32 成员随机排列，只重排上一帧的完整两通道空间场，当前目标不动。
固定种子 7100–7109，共 10 次，B/C 使用同样的排列；不重新训练。
允许随机排列偶然保留固定点，期望约 1/32 的成员不变。
每次前向输入只包含当前对的上一帧，不包含更早残差或下一个目标；没有跨时刻隐藏状态。
