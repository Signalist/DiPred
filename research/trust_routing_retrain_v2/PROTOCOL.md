# Trust routing retrain v2 固定协议

本轮只训练 `G_context` 和 `G_trust`，seed=42、各1000次 Adam(0.001) 更新。输入和路由实现全部复用 `research/trust_causal_audit_v2/`；不得调用旧 `error_guided_spatial_routing`。训练137窗口、开发36窗口，样本先按原轨迹等权抽样，再在轨迹有效窗口中抽样；两臂共享预生成1000步计划。

风险图、Key、缓存索引、当前历史读取和上一冻结原生反馈来自 v2 `data.py`。未来目标只在准备完成后作为损失/评分标签读取。R 的 log1p/p99 尺度固定来自137个训练窗口的 `RISK_NORMALIZATION.json`。反馈来源是冻结原生影子模型，不是新模型闭环；旧TF32反馈可作历史输入，新的FP32基线必须由 `native_sample` 和相同实际噪声生成。

两个1269参数路由器来自 v2 `model.py`，同一42号初始化和同一输入条件；唯一差别是固定 `lambda=beta=1` 的 Trust 先验。每步处理完整32成员、完整20帧和两通道标准化经验CRPS，含完整成员间距离项。候选只包括硬关闭原生、250、500、1000；选择按轨迹内窗口平均、轨迹等权的CRPS，平分优先原生/更早步。初始化启用路由仅作诊断。

两模型均选择原生时，不执行测试窗口推理；否则只允许固定test start480、目标500–519及一次Trust错位图描述。正式测试不允许替换缓存、时段、种子或超参数。

有效协议更新严格为2000。执行中两个实现级失败尝试分别保留在 `ATTEMPT_1_FAILURE.json`、`ATTEMPT_2_FAILURE.json`；失败中间权重不进入最终产物和选择。
