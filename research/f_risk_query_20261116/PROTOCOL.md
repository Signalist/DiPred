# RealPDE F 风险读出与查询先导（2026-11-16）

本轮根据用户附件的推荐组合①＋⑥，附带②局部可靠性审计开展。仅原 RealPDE train_real；所有新增拟合使用 seed=42。五场景不训练，新测试不打开。训练/校准/开发沿用旧 manifest 的互斥轨迹和 Re 组；开发集本身历史使用过，结论是探索性。原权重/结果只读。

1. 重新提取实际四步 DiPred 的点预测 P 和末次 up2 隐表示 F；风险训练使用原训练轨迹的 200:600 范围、819 个窗口，预测器只在其前200帧拟合过。校准与开发使用各自前200帧的9窗口。所有字段为 2×20×32×64，标准化来自原训练集。F、确定性 F、随机 F 的均值方差仅在风险训练数据计算。
2. 中心/形状分解：复用 seed42 最新共享参考 F/P 与 X/XPF 头，对比原分布、把中位数换成共同真实 P 后的分布，报告中心 MSE、CRPS 和区间评分。随后从头拟合共同中位数固定为 P 的等容量风险头 X、P、F、XPF、Fdet、Pprojection、Frandom、Fshuffle；统一2000更新、batch4、同初始参数/抽样顺序、AdamW和精确pinball。确定性 F 使用已有同网络结构6000次MSE训练的一调用CNN；调用次数与训练方式有差异，因此仅为控制，不单独证明扩散训练目标的因果优势。所有风险头预测同一个 DiPred 的误差，不随特征源切换误差目标。
3. 局部审计：全体；lead1–5、6–10、11–20；四个固定空间象限；根据预测场梯度、按训练80%分位阈值分出的高/低梯度区域。共10组，全部在预测时可确定。审计原始区间和独立校准集拟合的全局CQR区间。像素不视为独立轨迹，不声明严格条件覆盖。
4. 查询先导：矩形空间域＋未来时间段。两种统计量是区域时段均值与单速度分量最大值；用共享分位函数回答超阈概率。X、P、F、XPF使用相同模型和预算。训练/开发查询列表先固定，分别考察已见查询、新空间、新时间、两者均新；阈值仅用训练最大值的50/75/90分位确定。原生8/32路径实际生成一次并复用所有查询；不按每查询重复计费。报告均值/最大值CRPS、最大值事件Brier、可靠性、固定开发阈值下的误报漏报，以及区域/时段包含关系违例。分位函数提供阈值单调性，不预先承诺区域单调性。若F跨查询性能不优于X/P，则保留负结果，不强加复杂一致性模块。
5. 本轮为方向筛选，开发指标不用于反复选择模型检查点；固定末次权重。结果、模型、逐窗口/逐查询统计、训练记录、独立数值核验与中文结论一起保存。首先检验①和⑥是否成立，再按证据安排必要后续。附件中六条路线是候选，不同时实现六套系统。
