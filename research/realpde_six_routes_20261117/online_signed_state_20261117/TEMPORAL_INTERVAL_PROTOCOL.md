# Frozen block-task temporal interval comparison

Unit convention frozen during field-data collection, before any temporal interval evaluation: divide each task's signed errors and KI by its already frozen training task scale for the AcMCP/PID recursion, then transform endpoints back. This avoids making the first-step unscaled learning rate depend arbitrarily on the task's physical units. No development-derived scaling is used.

This is a separate continuous-feedback experiment on the same12 development trajectories, not new independent confirmation. Read original RealPDE windows at starts0,20,...,800. Each prediction is made at start+20 for the next20 frames; full truth is delivered at start+40. The first10 full blocks are an explicitly charged common warm-up. Evaluate the remaining31 blocks per trajectory. Every field/state/calibration method receives exactly the same full20 feedback; no history crosses trajectories. This fills the gaps in previous split-specific evaluations and therefore must not be compared as if it reproduced their cold starts.

Reuse frozen state models,32-member lowcost joint distribution, and the90-window fixed field offsets. Save the same five physical tasks for raw/fixed/online fields and corrected deterministic point fields. No model is selected on this dense experiment. Primary uncertainty comparison: empirical90% task coverage, training-scale-normalized interval score and width, plus existing empirical functional CRPS. Report individual tasks, not only their average. Nominal coverage is a target, not a claimed guarantee.

Temporal controls use signed task errors J(Y)−J(corrected P), with the same common raw P defining MVPE. They return scalar task intervals only; they do not generate joint fields or change the field point forecast. Compare fixed empirical calibration on90 separate windows, rolling last10 empirical residual quantiles, SPCI-style conditional residual QRF, and the AcMCP block-h=1 recursion. SPCI uses10 trees, maxdepth2, lag3, five beta values from0 to.1, minimum predicted90% width. A standard leaf-weighted quantile regression forest using sklearn trees replaces the author's sklearn_quantile dependency; training pairs use actual within-trajectory history only. No bootstrap re-training of the common frozen point predictor. Report lag1/lag5 sensitivities as such. This is a disclosed fixed-predictor SPCI adaptation, not byte-identical author-package execution.

AcMCP h=1 reproduces the author's asymmetric P+I+D recurrence, with ncal10, rolling last10, lr.1, Csat computed from predeclared Tg=1000, delta=.01, and the h=1 mean-error scorecaster after10 feedbacks. KI is explicitly max absolute task residual on separate calibration windows, avoiding the reference function's full-series default. Report lr.05/.2 sensitivities and PID without scorecaster. Python translation is needed because Rscript is absent. Audit against an independently indexed batch recurrence. Retain any infinite or reversed intervals; do not silently clip them into finite successes. h=1 is the20-frame task-block index; no claim to validate AcMCP's frame-level MA(h−1)/cross-horizon component. A dense frame-h=20 benchmark would require a distinct issuance/feedback protocol.
