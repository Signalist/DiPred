# Signed state identification: frozen stage-one protocol

Primary objective: improve physical u/v field MSE in observed-history20→20 prediction using legally revealed signed residuals. Original RealPDE only; frozen current four-step predictor; seed42; trajectory-disjoint train/cal/development. Later/future are the same development trajectories and historical exploratory reuse is disclosed. This protocol is written before this directory's calibration or development state-model results.

Eight physical residual modes: two global u/v bias modes and six uncentered train residual POD modes orthogonal to them. Orthonormal under mean physical field inner product. This allows exact reconstruction-error accounting; target-assisted projected residual is an oracle diagnostic, never an issued state. Fit basis and feature projection on train only. No latent coordinate is called Reynolds number or a physical parameter.

Candidate models: global rolling bias;8-mode exponential residual memory; train-fitted VAR(1); random-walk Kalman; stable VAR Kalman; optional current X/P/F16PC conditional mean plus latent innovation Kalman; direct linear current-feature/last-residual predictor; small GRU16 reading the same current feature and last revealed residual. Use a small fixed grid for ridge/noise/update rate/shrink and select each family by trajectory-equal calibration MSE. Keep zero shrink and report all failed candidates. Compare existing full-field gated residual subspace memory on the same revealed errors and the prior2967parameter local warp with no feedback.

Issue at history start+20, reveal at start+40. Each split/trajectory cold starts independently. Predictions for a window are formed before its target is read by the controller. Update only after the full block arrives. For gaps, learned state transitions propagate the actual integer number of20-frame steps; missing windows give no feedback. RNN gap is an explicit input. No retrospective reissue.

Controlled drift diagnostic, not new PDE evidence: take real forecast/target pairs and add a prescribed forecast-side physical bias after the midpoint of each trajectory. Bias is two global velocity offsets of ±0.5 times training component residual RMS, alternating signs by sorted trajectory id. A second ramp changes the same bias linearly over the post-change half. All methods see the same shifted P, no access to injected offset label; their F remains that of the frozen original predictor. Do not call this an unknown physical parameter change. Select models only on natural calibration, then freeze before all drift/development runs. Report cold/post-change MSE and excess-error recovery by window rather than selecting a favorable recovery threshold after outcomes.

Required subsequent verification before calling the online route complete: independent MSE/POD and causal prefix/trajectory isolation checks; direct observed-input inference; raw/fixed/online common probability calibration and scores; faithful SPCI/AcMCP comparison with explicit block-vs-frame horizon semantics;200-frame free rollout with no fabricated residual feedback (cold and legally warmed state). Natural gains and injected-bias adaptation must be distinguished. Do not treat this first-stage protocol or partial MSE results as proof that all of these requirements are met.
