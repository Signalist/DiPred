# Direct field correction controls, frozen before fitting

Purpose: close the explicit ResCrct / ordinary residual / compute-comparable refinement gap in the original six-route objective. This is additional exploration after the earlier signed-structure results; all dev/late/future trajectories have prior reuse. No fresh confirmation claim.

Data/information: original released RealPDE real data only, seed42. Same819 correction-training windows/46 trajectories,90 calibration/10,108 dev/12,late120/future72 from the same12. Frozen four-call DiPred and actual batch1 P are reused. The correction task observes only X[20] and forecasts Y[20], no revealed previous errors or extra future observations. Train is later frames of backbone training trajectories, with no temporal overlap with original first200 backbone fit. No new main predictor or latent autoencoder. Labels are real forecast residuals, not noise-added targets.

References: frozen local warp_F_last (2967 parameters) and old smooth additive_F_last (2984), with their original choices unchanged. New controls:
1. Dense F additive head: same frozen32-channel4×8 projection as the selected warp, hidden14,1×1/3×3/1×1 convolutions,40 output channels for2×20 leads, spatial bilinear upsampling. No2×4 coefficient pooling or4 temporal nodes. Delta bounded by0.25 tanh, as the prior additive arm.2840 parameters, close to warp.
2. Ordinary XP additive: full20×32×64 three-layer3D convolution,4→8→8→2,3042 parameters. Zero readout initialization, unconstrained additive output. It is the cold original ResCrct topology with unused zero feedback inputs removed and smaller width.
3. Original ResCrct: import exact Shared/models.py Corrector(width24),22082 parameters. Train independently with r=m=0 throughout; output P+delta. This is a cold, no-feedback adaptation, not the original online protocol or an ablation of previously feedback-trained weights. Inactive first-layer weights remain counted and explicitly disclosed.
4. Existing offline BlockResidualCorrector: import exact Shared/crossfit_corrector.py,25842 parameters, full-history encoder and spatiotemporal residual, no past feedback. Separates the local time-aligned history topology from the repository's full-history alternative.
5. Deterministic two-pass refinement: shared3D6→7→7→2 network,2851 parameters, receives X,originalP,currentQ, spatially average pooled2× before each pass; upsample delta and add0.5delta per pass, starting Q=P.1000 optimizer updates×2 network calls, same2000 corrector-network training-call count as single-pass controls. Actual FLOPs/wall time need not match. It is a simple deterministic refinement control, not a PDE-Refiner paper reproduction.

Training: batch8, AdamW lr3e-4 cosine to1e-6,weight_decay1e-5,clipgrad1. Each arm's seed42 generator uses the same minibatch index prefix.2000 updates for one-pass models;1000 for two-pass. No data augmentation. Physical MSE divided by the shared velocity variance scale. Sole post-training selection is scalar gain {0,.25,.5,1} on trajectory-balanced calibration physical MSE; no dev early stopping or model modification. Retain gain1 and selected-gain results, training loss traces and time. Family winner is calibration-selected before dev use.

Primary endpoint: equal-trajectory physical velocity MSE on observed-history dev, with late/future extensions separate. Strong comparison against frozen warp, original P and the new calibration-selected direct-control winner. Per-Re/trajectory bootstrap and harmed-window fractions. Secondary physical task errors use fixed goal_task_error tasks; do not change primary metric based on them.

Cost: initial pre-fit architecture timing, final interleaved batch1 end-to-end and correction-only latency, memory and serialized size on A100.
