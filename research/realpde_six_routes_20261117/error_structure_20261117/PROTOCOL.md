# RealPDE 结构误差探索，seed 42

2026-11-17，任何本目录实验运行前冻结此协议。原始目标见用户附件；本目录不是对六条路线的缩减。

## 范围和判断

使用当前发布的 DynamicsDiffusion20 四步零噪声预测。只用原 RealPDE 小数据，单训练种子 42；保持旧权重和结果不变。主任务为有完整真实历史的 20→20 预测，主要指标为轨迹等权物理速度 MSE。归一化单位 MSE、分 Re 结果和物理量误差作为辅助指标。

误差诊断先在训练/校准进行：限制在整窗口共享的小空间位移（±1 网格）、时间相位（±1 帧）、两分量振幅（±25%）和偏置（±0.25 标准化单位）共 7 个参数。线性切向投影只作诊断；真实修正通过非周期边界 grid_sample 作用于未来 P。目标辅助 oracle 只能表明结构存在，不能当预测能力。再对 4 个 5 帧段独立参数作上限补充，不作初始学习器。

学习器首先使用 7 参数线性岭回归。X、P、XP、不同层 F 及 XPF 的池化描述量分别经过仅训练数据拟合的 64 维 PCA；读出容量一致。普通加性修正采用仅训练残差学习的 7 维平滑 PCA 模态、同样的特征及岭回归。小数据比例按完整训练轨迹嵌套取 25%、50%、100%，不是新训练种子。

岭系数 {0.01,0.1,1,10}，收缩 {0,0.25,0.5,1}，只在 calibration 选择。development 不调参；后期窗口仅作同轨迹时间延伸，不能算新独立确认。所有历史重复使用的 split 明示为探索；不得据此宣称论文级独立验证。

TF32 override=0，候选和基线一起 FP32 重算。捕获同一次四步中的 up2/中间 latent，不增加主干调用。不把一调用 Fdet 与四步 Fdiff 差异归因为训练目标；同四步、同增量输入的确定性控制另补。

## 全目标证据账本（待完成项目必须继续）

1. 结构化修正：受限 oracle → 合法预测修正 → 同预算加性修正/现有 ResCrct → 无反馈滚动 → 误差机制可辨识合成检查。
2. 低成本联合分布：训练真实残差的低秩/相关模型，对固定边际、32 样本比较 ECC、smooth、N-ECC；实际耗时/显存及重排后的物理量。
3. 在线潜状态：完整窗口反馈后更新有符号低维系数，比较滚动偏置和 memory，评估漂移恢复与滚动；必要时补同信息 RNN/SPCI/AcMCP，对各方法能力边界明确说明。
4. 主动观测：明确新增观测时刻和预算，同化模块相同，比较均匀/随机/方差/风险/VOI 的观测数—未来误差；不能混为原预测任务。
5. 计算分配：训练上记录真实动作收益，以预测前量决定动作；相同预算比较随机/风险/区间/预测收益，实际成本曲线及 oracle 上限。
6. 任务物理证书：审查方程/边界/离散误差是否可用；真实 PIV 不具备保证条件时只报告经验任务误差估计与失败边界，不伪造严格证书。
7. 横向要求：F 同四步确定性控制、同容量 X 编码器、学习曲线、未见 Re；相同原始/固定/在线校准口径；轨迹级不确定性；三种预测任务分别评价；预先确定主要用途。

现有 joint_structure_20261117 的平滑重排收益仅是方向 2 的强基线；六条路线并未因此完成。无新鲜轨迹时不能宣称独立确认，需明确此限制并保留目标。
