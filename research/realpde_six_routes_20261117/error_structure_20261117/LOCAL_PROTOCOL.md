# 局部结构可学习性（2026-11-17）

设计触发证据：在 calibration 上，global7 oracle 改善 5.36%，4×5 帧分段的 28 参数 oracle 改善 7.66%，2×4 平滑空间系数的 56 参数 oracle 改善 18.77%；仅位移/相位为 13.25%，仅振幅/偏置为 8.83%。这属于校准数据辅助的探索设计，development 尚未进入本轮脚本。

采用三层小卷积头：同一训练数据拟合的 32 维逐位置 PCA 输入、隐藏宽度16、1×1/3×3/1×1卷积。全819训练窗口，seed42，2000更新，batch8，AdamW，学习率3e-4余弦至1e-6。只校准整体修正强度 {0,.25,.5,1}，无开发集早停或调参。

结构头输出7×2×4平滑系数，约束与global7相同。普通加性头输出2分量×4时间节点×2×4空间节点，线性插值到完整未来20，标准化残差幅度限制±.25。两头仅最后层相差一个通道，约三千参数；具体计数保存在权重中。所有方法改变实际未来场。

比较 X、XP、F_last、F_mid0、XPF_last、XPF_det4_6000。P固定使用同一DiPred，不以确定性模型输出替换P；F_det来自同四步、同历史增量结构的确定性训练。Fdet6000训练计算量较多，须明示。主结果为各家族只凭校准选定的全数据模型，所有变体均保留。

局部oracle和模型都不强加二维不可压缩约束。若学习失败，结论限于此小模型/本数据/受限局部参数化，不扩展为所有误差结构不可学习。
