# 49 independent XPF16 dual-quantile experiments

This study uses the current `main` frozen four-call joint-20-frame DiPred and 49 independent 34,004-parameter XPF16 heads. Each head takes six existing base features, eight projected last-denoising features, and two coordinates, and produces exactly two quantiles. For alpha 0.01..0.49, train with the corresponding half-sum pinball loss. All heads begin with the same frozen pre-Q05 initialization, use the same training examples, seed42, batch sequence and 2,000 AdamW updates; the Q05 result is retrained independently. A four-model smoke validation occurs before formal fits.

`train49.py` is the serial reference. `train49_batched.py` computes independent models in groups of four, each with distinct parameters and Adam moments. Global gradient clipping is computed separately per model. Before use, `audit_batched_training.py` compares all weights after an identical update for Q01, Q05, Q25, Q49 against serial execution. A checkpoint every 250 steps supports resumption. The group wall time is shared work: do not sum it as independent GPU wall time.

Initial tail offsets come from the held-out calibration identities, separately for every alpha, endpoint and channel, using a fixed spatial 1-in-16 subsample across calibration blocks. After issuing an entire window, the next offsets are an exponential average (gain 0.5) with the per-trajectory, per-channel alpha/1-alpha quantiles of the previously issued model's observed residual minus the raw bound, using the same spatial subsample. If an offset-adjusted lower exceeds the upper, both are projected to their midpoint and the occurrence is counted. No guarantee of simultaneous coverage or out-of-distribution validity is claimed. Each controller owns independent state; no current-window truth is read before issuance.

8/32/256 are actual diffusion paths with seeds 500000..500255; shorter ensembles are prefixes. Generation batches two seeds at a time using the exact same individual initial noise; GPU convolution rounding can differ from serial calls. An independent 32-path audit records the observed maximum differences, and evaluation checks the previously saved 32-path moments. The prior 90% Gaussian *proxy* online scaling controller is fit separately for each sample count; the same scale is applied to all of that method's actual samples and quantiles are then computed as linearly interpolated empirical order statistics. The reported intervals are not Gaussian quantiles and are not guaranteed to achieve the targets. Finite sample size strongly limits the tail resolution, particularly for 8 paths. Fair CRPS after a scale fitted from the same members is reported as a statistic, not asserted to be unbiased for an underlying iid law.

For XPF distribution scoring, gather all 98 separately trained quantiles, interpolate Q50=(Q49+Q51)/2, optionally monotonically rearrange, interpolate linearly between adjacent percentile points, and assume Q0=Q1 and Q100=Q99. Trapezoidal integration of pinball at each 1% level gives approximate CRPS; outer-tail clamping creates 1% endpoint atoms. WIS uses 49 central intervals, weight alpha for each interval score plus one-half the absolute median error, divided by 49.5. PIT inverts the rearranged piecewise-linear quantile function and uses midpoint PIT for endpoint or other atoms. Results before rearrangement are diagnostics, not a proper CDF where quantiles cross. The empirical CDF in the point example pools snapshot residuals across sampled points and is descriptive, not a conditional CDF for that particular point.

Training, calibration, development and test trajectories are disjoint. However, the development/test trajectories and base XPF architecture were repeatedly used earlier in the project; this run cannot retroactively make them a fresh untouched test. It is an exploratory historical-test comparison, with no formal generalization claim. The 20-frame feedback constraint remains causal.

Full reproduction requires the original experimental workspace, data and prior checkpoints referenced by the scripts, not just the portable Git repository. New results go under `runs/xpf16_fullpercent_20261111` without overwriting prior studies.
