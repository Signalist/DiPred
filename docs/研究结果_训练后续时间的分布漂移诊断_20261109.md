# 区间中心与尾部尺度：较晚训练轨迹的时间创新诊断

44条长度足够的原训练轨迹。神经网络拟合截止600帧，固定原四步，580窗口冷启动作前导，600…760按完整20帧反馈。每个已知数据包均在当前真值读取前写出；真实残差另存。

目标是原始标准化残差r=(Y−P−区间中点)/原始半宽的尾部中心(q05+q95)/2及logq90|r|。它们不同于点预测MSE和最终区间Score。已知8维全局动力学摘要保留绝对量，不进行窗口内全局中心化。

仅用查询620/640/660/680的目标拟合共享上下文创新岭回归，分别按通道、风险头拟合。查询700/720/740/760作后续诊断；标签目标720:800未拟合。固定ridge0.25、标准差下限0.05、z截断±5、创新限幅，未扫描参数/折/种子。相邻窗口/轨迹相关，不作独立像素或显著性主张。
