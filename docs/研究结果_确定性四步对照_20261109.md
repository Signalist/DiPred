# 相同4步运算图的确定性端到端对照

本轮结果：相同4步推理图下，物理场原生去噪训练的零噪声输出，测试后段宏MSE为1.3455370e-4，确定性终点MSE训练的状态模型为1.4722425e-4，前者降低8.61%；标准化MSE降低8.69%。后者在固定训练窗口拟合更好、在未参与训练的Re组更差，因此当前收益没有被这个额外迭代计算对照复现。

将此前6个单次CNN和新增2个确定性4步模型全部纳入后，在本轮开发/测试6个Re工况、两个时段中，固定的物理状态DI零噪声候选在原MSE和标准化MSE上均优于逐工况最强参考值。部分差距很小；这是历史已用数据、单训练种子、固定预算下的探索结果，不是普适优越或独立创新的证明。

本轮补充此前尚缺的归因对照：将完整20帧Diffusion的零初始噪声4步运算图保持不变，从随机权重开始，只通过真实未来场的最终MSE反向传播训练。由此比较同样4次网络调用下，原生去噪训练和确定性终点训练的具体表现。

## 保持一致与实际差异

状态预测、末帧增量预测各训练一个模型；每个阶段都同时处理[B,2,20,32,64]，4次迭代是对同一未来20帧张量的细化，不是10+10或5帧物理时间分块。每个模型参数1,597,672，主干、时间嵌入、阶段混合系数和初始化均与物理场Diffusion一致。

所有新模型仅用47条训练轨迹前200帧、1551对20→20窗口、训练种子42、batch8和固定6000步。归一化来自同一训练集。没有开发/测试挑选、旧权重初始化、教师预测、蒸馏、交叉折或多训练种子。两个预测器冻结后才采样开发/测试，采样程序只读取观测历史，全部预测保存后再回放读取真值。

新模型不注入随机噪声，不抽样去噪时间，不使用去噪损失；只优化4步后真实未来的标准化物理MSE。原Diffusion每次更新只有1次随机噪声层级的去噪损失，推理零噪声版4次网络调用。新对照每次更新反传全部4次调用，因此只匹配更新数，训练FLOP不相同且新对照更高。32路径Diffusion均值需128次调用，另作为较高推理计算量参考列出。

图等价性在非零合成权重、非零随机输入下检查，并在新训练冻结后将旧Diffusion权重载入新运算图，重现已保存的零噪声预测；后一加载只用于审计，不进入新训练。

评测仍为每20帧揭示真实观测的窗口预测，不是800帧自由滚动。数据已有长期研究使用记录，本轮是探索性对照，不是新的外部验证。

## 解释边界

本轮原生去噪训练的零噪声4步胜过新控制，支持这套去噪训练流程在当前设置中的实用价值。比较中的两种4步点预测都完全确定，因此结果不证明随机推理是必要机制，也不能把去噪目标、噪声条件训练和优化路径的影响逐一分开。

本轮控制只优化一个固定预算/初始化，训练目标和训练计算量与原生去噪不同；不能据此推广到所有确定性或扩散求解器。未给新确定性模型训练风险头或校准预测区间，因此这次点MSE实验不构成区间可靠性的胜负结论。

v相同色标图在v_snapshots.png，固定3750_20和22875_10、目标索引799，不按改善幅度挑选。差分能量为相邻网格平方差，没有物理间距因子，逐通道结果保存在summary.json。
