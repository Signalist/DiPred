# 去掉表征压缩：物理场直接20帧扩散对照

本轮得到的进展是：物理场完整状态Diffusion在测试3个Re工况、主时段和额外时段的原数据MSE均低于本轮六个CNN的逐工况最优值；与AE-Diffusion的测试宏MSE基本持平。省去编码器并未明显损失当前平均精度，但高Re标准化MSE仍有反例，细节偏平滑未解决，零噪声4步输出也与32样本均值接近，尚不能将点预测收益归因于随机采样。

本轮检验：上一轮潜状态增量未改善整体结果，瓶颈是否与编码压缩有关？新增物理空间完整状态/末帧增量Diffusion，以及各自相同主干CNN，全部从头训练。以下保留全部工况和指标，不根据已用测试结果选择性汇报。

## 数据和结构

沿用已审计的隔离划分：47条训练轨迹、10条校准、12条开发、12条测试。所有预测器只拟合训练轨迹的前200帧、1551对窗口，训练种子42，batch8，每个模型固定6000步；没有开发集选择、蒸馏、交叉折或多训练种子。复用的物理归一化只由这47条训练轨迹拟合。

四个模型主干初始化哈希完全相同，参数各1,597,672。每次输入20帧历史和20帧噪声场，一次输出全部20帧，状态形状[B,2,20,32,64]；4个去噪层级，无10+10/5帧递推。增量模型在标准化物理场上学习Y-X_last，生成全部20帧后加回X_last，不使用编码器、不新增修正网络。评测中每个新窗口使用已揭示的20帧观测，这是窗口反馈预测，不代表无观测的800帧自由演化。

Diffusion目标保持原生clean-state平方误差/(1-alpha_bar)，CNN采用相同目标坐标下的标准化物理MSE。四个预测器全部冻结后才访问校准、开发和测试字段。采样程序不读取目标真值；先保存所有预测，再独立回放评分和20帧反馈。

**计算边界：**物理主干在32×64上运行，潜空间主干在16×32上运行。两者宽度相同但输入输出通道、参数和空间计算量不同；潜空间版本另外进行编码器训练。本轮是具体实现和预算下的对照，不能把差异完全归因于表征，也不是等FLOP比较。Diffusion点预测使用32条4步路径，CNN仅一次前向，另报告Diffusion零初始噪声的4步输出。
