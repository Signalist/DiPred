# 动态风险记忆与同容量调幅对照

原四步DiPred和当前最好48340参数风险头完全冻结。只增加一个10430参数模块，输入已知物理预测、历史、去噪特征、坐标和已揭示误差的未来lead投影。输入总32通道，Conv3D32→12、GN、SiLU、Conv12→2；空间迁移和调幅两模块结构、初始权重、训练参数量、批次及优化完全相同。

warp输出未来每一lead的两个有界像素位移，4*tanh后向双线性采样上一误差投影特征；modulate以同样两输出给两个潜特征组0.5…2倍增益，不移动空间位置。两者均不改变点预测，初始模块末层为零，原始风险区间与当前最好逐位相同。位移不是物理流速，四个潜特征不是物理场变量。

只用原819对训练身份实际误差，2000步seed42、batch4、同AdamW/余弦学习率/20%可用性mask，原48340权重及归一化始终不变。零可用性时模块不使用历史误差，训练后原始冷启动区间仍与冻结头相同；但重新计算的校准系数可以改变最终冷启动区间。全部权重冻结后才读取10个独立校准身份。

原机制门槛要求迁移对调幅和冻结原头，均在八项训练身份后续汇总指标上不退步且Score改善超过1e-6。这个门槛失败，结果保持失败。迁移对原头在两种控制器下八项均严格改善，但对调幅在Score/宽度/排序/覆盖等指标仍有代价，不能证明空间迁移独有贡献。

另建立完整探索性后续，只问候选是否在全部原强参考和96项下减少退步，不重新拟合、修改原门槛或只报告有利控制，见[完整后续报告](研究结果_动态误差风险记忆完整后续_20261110.md)。对重复分析过的开发/测试进行后续，不是独立确认。

独立审计：NumPy双线性采样及位移有限差分梯度、零位移恒等、正x向右平移、边界非周期复制通过。两模块首批独立pinball梯度及一次更新逐位重现，全部原48340参数/缓冲不变，初始输出/不可用记忆冷启动不变；1760条当前冻结控制逐位复现，全部5280条pilot、2000步批次/mask、10对完整窗口先发后揭示及八项门槛重算通过。

拟合前32例的已学位移RMS约0.605像素，范围约[-3.899,3.355]；这只说明模块在移动特征，不证明移动方向对应真实误差传播。后续需要与反向和对称平滑操作区分，不能把非零位移当作机制证据。

原99→66→33→0、一次完整20→20、每完整20帧反馈及实际保存的上一点预测不变；没有5帧/10帧预测块、点预测残差Corrector、额外采样、交叉折、蒸馏或多训练种子。Score/Width为训练通道标准化无量纲指标，组覆盖误差先逐组取绝对值再平均。
